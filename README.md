# 📊 San Francisco Salaries Dashboard

## 📌 Project Overview
An interactive **Excel dashboard** designed to analyze employee compensation, payroll trends, and salary distribution across job titles from 2011 to 2013.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Excel Formulas
- Interactive Filters

## 📈 Key KPIs
- Total Employees
- Total Base Pay
- Total Overtime Pay
- Total Other Pay
- Total Compensation

## 🔍 Key Insights
- Total compensation increased from **$588.88M in 2011 to $624.04M in 2013**.
- Transit Operators recorded the highest total compensation.
- Base pay remained the largest component of employee compensation.
- 2013 recorded the highest average compensation.

## 💡 Business Recommendations
- Monitor annual payroll growth.
- Analyze overtime expenses by job title.
- Track compensation components to support better budgeting.
